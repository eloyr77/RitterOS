Unicode data: the capitals of the exFAT up-case table

What: scripts/exfat_upcase.c carries, as 183 runs, the one-to-one capitals
of the characters of the Basic Multilingual Plane: data of the Unicode
Character Database (version 13.0, as Python 3.9.6's str.upper() gives it),
which until step 63a Python supplied at build time (scripts/exfat_upcase.py,
since step 46c). From them the build makes the exFAT up-case table that
`format -t exfat` (user/lib/mkfs_exfat.c) writes onto every exFAT volume;
scripts/exfat.py (the tests' images) makes the same table from Python.
