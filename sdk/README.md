# The RitterOS SDK

Build programs for RitterOS in a repository of your own, copy them over SSH
to a PC running RitterOS, and run them there. The guide, for people and AI
agents alike, is [CLAUDE.md](CLAUDE.md); [API.md](API.md) lists every
header, function and macro a program can use; a new project starts from
[template/](template/); [examples/hellowin/](examples/hellowin/) is a
windowed app.
