The files are unmodified. All of them are installed as /system/fonts/NAME.bdf,
read by libwindow when a program asks for one (wfont_find). scripts/bdf2c.c
also compiles 9x15 and 9x15B into C tables at build time: the kernel's console
font, and libwindow's default (the fallback when a font file is missing or
cannot be read).
